## О проекте

`setup.sh` - Bash-скрипт для первичной настройки чистого VPS. Он обновляет систему, настраивает SSH, firewall и Fail2ban, управляет swap, включает необходимые системные параметры и при необходимости устанавливает Docker.

> [!IMPORTANT]
> Скрипт изменяет SSH, firewall и системные конфигурации. Не закрывайте текущую SSH-сессию до завершения проверки нового подключения. Перед использованием на production-сервере рекомендуется создать snapshot.

## Возможности

- Обновление системы и установка базовых утилит;
- Автоматический запуск внутри `tmux`;
- Добавление публичного SSH-ключа;
- Безопасная смена SSH-порта с проверкой и откатом;
- Отключение входа по паролю только после проверки ключа;
- Настройка UFW и Fail2ban;
- Включение IPv4 forwarding и BBR при поддержке ядром;
- Ограничение журналов systemd;
- Создание или изменение `/swapfile`;
- Установка Docker Engine и Docker Compose Plugin;
- Логирование и резервное копирование изменяемых конфигураций.

Каждый основной этап можно пропустить.


## Быстрый старт

Скопировать команду и выполнить в терминале с root доступом:

```bash
curl -fsSLo setup.sh https://raw.githubusercontent.com/RandomAlex123/vps-setup/main/setup.sh
chmod +x setup.sh
./setup.sh
```

## Что настраивает скрипт

### Обновление системы

Скрипт обновляет список пакетов, устанавливает доступные обновления и добавляет базовые утилиты для администрирования сервера:

- `curl`, `wget`, `git`, `jq`;
- `zip`, `unzip`, `tar`, `rsync`;
- `openssl`, `gnupg`, `ca-certificates`;
- `iproute2`, `dnsutils`, `socat`;
- `cron`, `logrotate`, `sudo`, `kmod`;
- OpenSSH Server и OpenSSH Client;
- UFW, Fail2ban и unattended-upgrades.

### Автоматические обновления безопасности

При подтверждении включается автоматическая установка обновлений безопасности:

- Ежедневное обновление списка пакетов;
- Автоматическая установка security-обновлений;
- Очистка кэша пакетов раз в 7 дней;
- Автоматическая перезагрузка сервера отключена.

### SSH

Скрипт может:

- Добавить публичный SSH-ключ выбранному пользователю;
- Изменить стандартный SSH-порт;
- Временно сохранить старый порт до завершения проверки;
- Проверить, что новые SSH-порты действительно прослушиваются;
- Разрешить новый порт в UFW, если firewall уже активен;
- Отключить вход по паролю только после успешного входа по ключу;
- Удалить старый SSH-порт после подтверждения;
- Автоматически откатить незавершённые изменения при ошибке.

До отдельного подтверждения текущая SSH-сессия и старый способ подключения сохраняются.

### UFW

При подтверждении скрипт:

- Устанавливает UFW;
- Запрещает все входящие подключения по умолчанию;
- Разрешает все исходящие подключения;
- Открывает только текущие SSH-порты;
- Проверяет наличие разрешающих правил после включения firewall;
- Восстанавливает предыдущие правила, если настройка завершилась ошибкой.

Другие порты автоматически не открываются.

### Fail2ban

Fail2ban настраивается для защиты SSH:

- Используется jail `sshd`;
- Backend — `systemd`;
- Учитываются все активные SSH-порты;
- После 5 неудачных попыток адрес блокируется на 1 час;
- Попытки учитываются за интервал 10 минут;
- Текущий IP можно добавить в список исключений;
- Предыдущая конфигурация восстанавливается при неудачном запуске.

### Системные параметры и BBR

Скрипт может настроить:

- IPv4 forwarding;
- IPv6 forwarding по отдельному подтверждению;
- Очередь `fq`;
- TCP congestion control `bbr`, если он поддерживается текущим ядром.

Настройки записываются в отдельный файл в `/etc/sysctl.d/` и проверяются после применения. При ошибке предыдущая конфигурация восстанавливается.

### Журналы systemd

При подтверждении настраиваются ограничения journald:

- Максимальный размер постоянных журналов — 200 МБ;
- Максимальный размер runtime-журналов — 100 МБ;
- Максимальный срок хранения — 14 дней.

После применения выполняется очистка старых журналов.

### Swap

Скрипт:

- Отображает существующий swap, размер `/swapfile` и общий объём swap;
- Позволяет создать или изменить `/swapfile`;
- Принимает размер от 128 до 131072 МБ;
- Корректно отключает старый `/swapfile` перед заменой;
- Добавляет `/swapfile` в `/etc/fstab`;
- Восстанавливает старый swap-файл при ошибке активации или обновления `/etc/fstab`.

Существующие swap-разделы не удаляются.

### Docker

Docker устанавливается только после отдельного подтверждения.

Скрипт:

- Добавляет официальный репозиторий Docker;
- Устанавливает Docker;
- Включает и запускает сервис Docker;
- Проверяет успешность установки.

### Логи, резервные копии и итоговая проверка

Скрипт сохраняет лог выполнения в:

```text
/var/log/setup.log
```

Резервные копии изменяемых файлов сохраняются в:

```text
/var/backups/setup/<дата-и-время-запуска>/
```

## tmux

Скрипт автоматически устанавливает `tmux` и продолжает работу в сессии `vps-setup`.

Для повторного подключения к сессии:

```bash
tmux attach -t vps-setup
```

## Предупреждение

Перед запуском изучите исходный код и убедитесь, что у вас есть доступ к web-консоли или rescue mode. Ответственность за итоговую конфигурацию и безопасность сервера остаётся за администратором.
